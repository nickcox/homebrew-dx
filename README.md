# homebrew-dx

Homebrew tap for `dx`.

## Install

```sh
brew tap nickcox/dx
brew install dx
```

The fully qualified formula token is:

```sh
brew install nickcox/dx/dx
```

## Migrating From cdex

The formula was renamed from `cdex` to `dx`. There is no compatibility alias.

```sh
brew update
brew uninstall cdex
brew install dx
```
